# Concrete Compressive Strength Prediction Using Polynomial Regression

## Project Overview
This project focuses on predicting the compressive strength of concrete using Machine Learning techniques, particularly Polynomial Regression.

The project uses the Concrete Compressive Strength dataset, which contains 1,030 records and 9 features (8 independent variables and 1 target variable).

## Dataset Features
The dataset includes:
- Cement
- Blast Furnace Slag
- Fly Ash
- Water
- Superplasticizer
- Coarse Aggregate
- Fine Aggregate
- Age

**Target Variable:** Concrete Compressive Strength (MPa)

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Importing the dataset
2. Understanding the data using `df.info()`
3. Checking missing values
4. Separating independent and dependent variables
5. Implementing Linear Regression
6. Generating Polynomial Features (Degree 3)
7. Training the Polynomial Regression model
8. Evaluating model performance using MSE and R² Score

## Objective
To understand how different concrete ingredients and curing age influence concrete strength and to predict compressive strength using Polynomial Regression.

## Project Learning
This project provides practical experience in data exploration, feature transformation, regression modelling, and Machine Learning evaluation.
